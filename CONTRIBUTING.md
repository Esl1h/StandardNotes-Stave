# Contributing to StandardNotes Stave

Thanks for helping out. This is a small, focused editor: a music notation and tablature editor for Standard Notes that keeps the note as plain notation text (ABC, alphaTex) and draws and plays it alongside.

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Development setup

```
git clone https://github.com/Esl1h/StandardNotes-Stave.git
cd StandardNotes-Stave
npm install
npm start
```

`npm start` runs the dev server at `http://localhost:3004`.

To test inside your Standard Notes app:

```
npm run build
npm run server-cors
```

Then install `http://localhost:3000/ext.dev.json` via Preferences > Plugins
(dev extension, separate identifier).

## Before opening a PR

1. `npm run typecheck`
2. `npm run lint`
3. `npm run format:check`
4. `npm test`
5. `npm run build`
6. `npm run e2e` (run `npx playwright install chromium` once first)

All six must pass. CI runs the same steps.

## Tests

A new feature comes with tests that cover it, and a bug fix with a regression test that fails without the fix. Unit tests live next to the code in `src/` (Vitest); behavior that needs a browser goes in `e2e/` (Playwright). The code style is enforced by ESLint and Prettier (`npm run lint`, `npm run format:check`).

## Commit messages

Follow [Conventional Commits](https://www.conventionalcommits.org/): one
logical change per commit, subject in the imperative mood, body explaining
the why when the what is not enough.

## Releases

Maintainers: the steps are under [Releases](README.md#releases) in the README. `CHANGELOG.md` is generated by git-cliff from the commit subjects, so a `feat` or `fix` subject is what users will read there.

## Scope guidance

The note stays plain notation text that is readable and usable without the plugin. Features that store data or UI state inside the note, fetch anything at runtime (CDNs, telemetry, AI providers) or add a dependency from a git URL do not fit the project. A new notation goes behind the `Engine` interface in `src/core/engine.ts`; the UI must not need changes for it.
