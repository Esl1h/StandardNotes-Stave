# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-10-27

### Fixed

- **abc:** Read warning text with an inert parser

### Documentation

- Show the OpenSSF Best Practices badge

## [1.0.0] - 2026-10-27

### Added

- **alphatex:** Import score files into alphaTex
- Print the score or save it as PDF

### Fixed

- **csp:** Default to the plugin's own origin
- **a11y:** Give secondary text AA contrast
- **a11y:** Name text tools by what they show
- **a11y:** Let the keyboard scroll every pane

### Documentation

- Record why Verovio is left out
- List import and printing
- Describe 1.0 and the community export
- Refresh the screenshots

## [0.4.0] - 2026-10-27

### Added

- Lay the music out in one long system
- Loop the selection
- Format the source
- Insert from a drawer with the bars hidden

### Fixed

- Keep the bar toggle next to the notation

### Documentation

- List the layouts, selection loop and format

## [0.3.0] - 2026-10-27

### Added

- **alphatex:** Draw at the size of the ABC staff
- **alphatex:** Place notes on the track's tuning
- Open each notation's example
- Add a metronome and a count-in

### Fixed

- **alphatex:** Hide the overlapping tuning legend
- **abc:** Play every track on the piano

### Documentation

- Show more of each notation in the examples
- Show both examples and bass tracks
- List the metronome and the count-in

## [0.2.0] - 2026-10-27

### Added

- **alphatex:** Write alphaTex for the toolbar
- **alphatex:** Highlight alphaTex and its tags
- Let engines offer views and track controls
- Show why an export failed
- **alphatex:** Render, play and export alphaTex

### Documentation

- Document the alphaTex engine

## [0.1.1] - 2026-10-26

### Fixed

- Show the caret and selection in the source
- Set the panes apart on dark themes

## [0.1.0] - 2026-10-26
