# Piano samples

`FluidR3_GM/acoustic_grand_piano-mp3/` holds the acoustic grand piano of the Fluid R3 General MIDI SoundFont, one MP3 per key, as rendered by the [midi-js-soundfonts](https://github.com/paulrosen/midi-js-soundfonts) project (commit `cbd6b6f6d1af89ebfb69402860741288f08ff8b7`, files checked against their git hashes). The ABC player loads only the notes a piece plays, from here instead of a CDN.
